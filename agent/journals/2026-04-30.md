## 10:09
Created `kalshi-dropcopy-puller` app crate. New app in `app/crates/kalshi-dropcopy-puller/`. Connects to Kalshi FIX gateway using KalshiRT session (KalshiFixSessionOps with listener_session=true by default for KalshiRT target_comp_id), re-encodes received application-level FIX messages to wire bytes (using FixEncoder), and publishes raw bytes to Kafka topic `digital.kalshi.fix-drop-copy`. Session-level messages (Logon, Logout, Heartbeat, TestRequest) are filtered out.

Config comes from conductor `default_api_keys` — looks for a key with venue=KLSH or target_comp_id=KalshiRT. Kafka producer config comes from the standard `kafka_producer` builder method.
