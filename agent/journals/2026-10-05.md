## (equity perp market cap research)
Eric asked whether Binance/Hyperliquid expose market cap for equity perps. Findings: Hyperliquid HIP-3 (xyz etc.) — no share count anywhere in info API (meta/assetCtxs/perpDexs). Binance fapi exchangeInfo — no share field on TRADIFI_PERPETUAL (213 symbols, 175 EQUITY). Share count does exist as `cs` on undocumented web endpoint `www.binance.com/bapi/asset/v2/public/asset-service/product/get-products` for bStocks spot pairs (e.g. NVDAB cs=24e9); covers 86/175 equity perps; values are rounded. token-info bapi endpoint returns mc/cs null for TradFi. Note fapi.binance.com geo-blocks from Eric's machine; www.binance.com/fapi works.
Follow-up: exhaustive HL search. No share count/mcap for perps anywhere — info types perpAnnotation/perpConciseAnnotations/perpCategories only give category/description/keywords. HL frontend hardcodes marketCap:null for perps (only spot via assetCtx.circulatingSupply; CoinGecko for some majors). trade.xyz frontend computes mcap for spot only, no separate backend. Useful: perpAnnotation descriptions state share unit (e.g. xyz:BABA = 1 ADS = 8 ord shares, xyz:SKHY = 1/10 share, Asian names FX-converted). vntl:ANTHROPIC/OPENAI/SPACEX price = valuation in $B (price IS mcap).
